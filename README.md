> **자기주도 학습의 시작과 끝, 쿼디.**
> 학습 성향을 찾아 공부법·자료·동일 성향 코치까지 맞추는 AI 자기주도학습 OS, 쿼디의 브랜드 아이덴티티(CI/BI)부터 AI 홍보영상 기획까지 한 번에 정리한 프로젝트입니다.

`브랜딩` · `BI/CI` · `AI 광고영상` · `Veo / Flow` · `대학원 AI 광고영상 과제`

## 📌 프로젝트 개요

쿼디 브랜드를 **로고(CI) → 컬러·타이포(BI) → 적용물(홈페이지·비품) → 홍보영상 기획**까지 일관된 시스템으로 구축했습니다. 동시에 대학원 **'AI 광고영상' 과제**(스토리보드 + 광고 MP4)를 겸한 결과물입니다.

- **목적:** 일관된 브랜드 시스템 구축 + AI 생성 도구를 활용한 광고영상 기획·제작
- **범위:** 브랜드 본질 → 로고 → BI → 적용물 → 광고 캠페인/스토리보드/프롬프트
- **방식:** 전략·디자인 합의 후 산출물 제작, 영상은 AI 도구로 생성(프롬프트 제공)

## 🎬 AI 광고영상 — 캠페인 A "들여다보다"

- **길이/화면비:** 약 58초 / 16:9 · 끝 4~5초 브랜드 인지
- **메시지:** 성향마다 맞는 공부법이 다르다 — 쿼디가 찾아준다
- **메타포:** 돋보기 렌즈로 학생을 들여다본다 (= 로고)
- **출연:** 민준(중3 남·원칙주의형) · 동생 서아(초등 고학년 여·전체주의형) · 동일 성향 코치 2인

**기승전결 (10씬)**
1. **기 (S1–S2)** 막막함 → 흐릿함(문제 공감)
2. **승 (S3–S4)** 5분 학습 MBTI 검사 → 민준 성향 발견(감각·순차 / 원칙주의형)
3. **전 (S5–S8)** 민준 맞춤법(구체·단계적) → 동생 대비(직관·총체 / 전체주의형, 전체흐름·연결) → 동일 성향 코치 매칭
4. **결 (S9–S10)** 돋보기로 본 결과 2배 이상 → 브랜드 인지

| 단계 | 주력 | 대체 |
|---|---|---|

| 내레이션 | ElevenLabs (한국어) | Typecast |
| 편집·합성 | CapCut | DaVinci Resolve |

**일관성 전략**
- **캐릭터(cref):** 인물별 레퍼런스를 Flow **Ingredient**로 고정(민준·서아·코치2). 멀티 캐릭터 컷은 쌍별 생성 후 편집 합성.
- **스타일(sref):** 고정 스타일 레퍼런스 + 공통 스타일 블록(따뜻한 가정 조명, cream+ink+4색, 16:9).
- **브랜드:** 로고·4색·유형명·그래프·자막은 **벡터 후반 합성**(생성 X).
