# 플랜코치(PlanCoach) — 프롬프트 엔지니어링 1주차 과제

소상공인 정부지원사업 사업계획서를 코칭하는 AI 페르소나 **'플랜코치'**를 설계하고, 이를 공통 재료로 (1) 모델 비교·선정, (2) 시스템 설계, (3) 실행 로그 검증까지 수행한 프롬프트 엔지니어링 과제 결과물 모음입니다.

- **대상 과업:** 창업 경험이 없는 소상공인 대표의 사업계획서 '사업 아이템(사업 개요)' 작성 코칭
- **테스트 시나리오:** 20년 요식업 경력 / 한식 전문점 창업 / '소상공인 창업 지원사업' 지원
- **핵심 설계:** 페르소나 + 프롬프트 4단 사다리 **v1(Zero-shot) → v2(+페르소나·안전장치) → v3(+Few-shot) → v4(+단계적 추론 유도·출력 형식)**

## 1. 모델 비교·선정 보고서 (결과물 1)

동일한 v4 합본 시스템 프롬프트와 동일한 사용자 입력을 **3종 모델(Gemini 3.1 Pro / Claude Opus 4.8 / GPT 5.5)**에 넣고 5축으로 채점했습니다.

| 평가 축 | Gemini | Claude | GPT |
| --- | :---: | :---: | :---: |
| 심사기준 반영·진단력 / 사실 안전성 / 간결·형식 / 초보 실행력 / 되묻기 유도 | **20** | **22** | **22** |

- **선정 결과:** Claude·GPT **공동 1순위**(각 22점), Gemini 차순위(20점).
- **선정 근거:** 정부지원사업은 '사실 정확성=신뢰'인 영역이라 **안전성**과 **초보 실행력**을 핵심 기준으로 둠. Gemini는 질문자가 하지 않은 일을 단정하는 예시("이미 구축했습니다")로 안전성 축에서 감점.
- **추가 관찰(과제목표 ② 실증):** 성능이 다른 세 모델이 동일 시스템 프롬프트를 받자 호칭·되묻기·안전 태도·다음단계 유도를 모두 공통으로 지킴 → **잘 설계된 페르소나가 모델 간 품질 바닥을 끌어올린다.**

## 2. 시스템 설계 문서 (결과물 2)

'플랜코치'를 누구나 동일하게 재현할 수 있도록 설계 전반을 담았습니다.

- 문제 정의 / 타겟 사용자 / 재사용형 입력 템플릿 (§1)
- 페르소나 정의 (§2)
- **v1→v4 프롬프트 전문**과 단계별 답변 (§3)
- 환각이 생기는 원리 (§4)
- 환각 검증 설계 — 검증 질문 5개 / 기대정답 / Pass·Fail 기준 (§5)
- 프롬프트 개선 이력 v1→v4 (§6)

> **핵심 발견:** 2026년 최신 모델은 v1(맨몸)에서도 기본기가 좋아, 프롬프트 강화 효과는 "못 하던 걸 하게" 만드는 게 아니라 **일관성·안전성·형식 준수를 점진적으로 끌어올리는** 방향으로 나타남. 가장 또렷한 증거는 v1→v2에서 호칭이 '사장님→대표님'으로 고정되고 안전 안내가 명시화된 지점.

## 3. 실행 로그 (결과물 3)

v4 플랜코치를 활성화한 **GPT**와 **12턴** 연속 대화를 수행하고, 환각·문맥 유지를 실제로 검증했습니다.

- **환각 트랩 2건:** 답변6 = **Fail**(모호한 사업명을 특정 공고로 임의 확정 + 마감·금액·배점 단정), 답변12 = **Pass**(월400×12=4,800만원 정답).
- **문맥 유지:** 타깃 변경(1인→가족)·예산 제약(5천만·5p)을 받을 때 변경분만 반영하고 강점·구조는 유지 → **내용 차원 Pass**. 단 페르소나 형식(호칭·간결·마무리 질문)은 흔들림.
- **핵심 성과:** 설계(결과물 2 §5)했던 환각 검증을 **실제로 포착**해, 결과물 1의 "안전성 축 모델별 편차" 결론과 연결.
